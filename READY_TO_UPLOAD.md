## 🔑 Authentication

When you run `git push`, you'll be asked for credentials:

**Username:** Your GitHub username  
**Password:** ⚠️ Use **Personal Access Token** (NOT your GitHub password!)

### How to Get Personal Access Token (1 minute):

1. Go to: https://github.com/settings/tokens
2. Click: **"Generate new token"** → **"Generate new token (classic)"**
3. **Name:** `Code Documentation Tool`
4. **Expiration:** 90 days (or No expiration)
5. **Select scopes:** ✅ Check **`repo`** (Full control of repositories)
6. Click: **"Generate token"**
7. **COPY THE TOKEN** (shown once only!)
8. **Paste as password** when git asks

**Save the token somewhere safe!** You'll need it for future pushes.

## 🚨 Common Issues

### "remote origin already exists"
```bash
git remote remove origin
git remote add origin YOUR_URL
```

### "failed to push some refs"
```bash
git pull origin main --allow-unrelated-histories
git push -u origin main
```

### "Permission denied"
- Use Personal Access Token (not GitHub password)
- Check token has `repo` permissions
- Try creating a new token

### "Support for password authentication was removed"
- This means you're using password instead of token
- Generate Personal Access Token
- Use token as password
