## 💡 Design Principles Applied

### 1. **Contrast First**
"If you can't read it, design doesn't matter"
- White text on dark backgrounds
- Dark text on white backgrounds
- Never similar colors touching

### 2. **Size Matters**
"Bigger is better for readability"
- 4rem headers (64px!)
- 1.5rem subtitles (24px)
- 1.1rem body text minimum

### 3. **Weight Creates Hierarchy**
"Bold gets noticed"
- 900 weight for main title
- 700-800 for section headers
- 600 for labels
- 400-500 for body text

### 4. **Shadows Add Depth**
"Flat is hard to see"
- Text shadows on colored backgrounds
- Box shadows on all cards
- Hover shadows for interaction

### 5. **Borders Define**
"Show where things are"
- 3px solid borders on sections
- Colored borders for branding
- Border changes on hover
